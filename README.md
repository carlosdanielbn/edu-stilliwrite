
# edu.stilliwrite.org

A cinematic educational platform concept inspired by Apple-style storytelling,
modern motion design, and emotionally intelligent educational experiences.

## Features
- Cinematic homepage
- Elementary school structure
- Subjects and grade organization
- Smooth visual hierarchy
- Interactive scroll effects
- Responsive layout
- Clean modern UI

## Deployment

Upload this project to GitHub and deploy with Cloudflare Pages.

## Suggested Future Stack
- Next.js
- Tailwind CSS
- GSAP
- Framer Motion
- Lenis Smooth Scroll

## Folder Structure

/index.html
/styles.css
/script.js

## Vision
Education should feel inspiring, elegant, calm, and beautiful.
